Gemensam Hamnplan – inloggning

Logga in med ditt Firebase-konto. Endast konton som lagts upp i Firebase Authentication och tillåts av Firestore-reglerna får komma åt planeringen.

Import görs endast efter bekräftelse och ersätter gemensamma uppgifter. Gör först en JSON-säkerhetskopia.

Flera fartyg kan ha samma namn. Välj rätt IMO i listan. Spara helst med IMO; utan IMO måste du välja registerposten innan du ändrar den. MarineTraffic öppnas separat och uppgifter fylls i manuellt.

Placera fartyg

Dra fartyg längs kajen med musen eller fingret. Placeringen räknas i meter utifrån pollarmåtten. Klicka på ett fartyg för att ändra det. Data synkroniseras till gemensam databas när du är inloggad.

Säkerhetskopian innehåller både fartygsregistret och kajplaneringen. Spara JSON-filen på ett säkert ställe, gärna i din Google Drive. Vid återställning visas innehållet och du får bekräfta innan befintliga uppgifter ersätts. Version 22 synkroniserar mellan inloggade enheter. Gör ändå regelbundna säkerhetskopior.

⚙ Kartkalibrering (öppna vid behov)
Kalibrera pollare på kartan (test)

Välj en pollare i listan till vänster. Klicka sedan på ”Markera pollare på kartan” och därefter på den verkliga gula pollaren på flygbilden. Kalibrera västra och södra kajen var för sig. På södra kajen rekommenderas P60, P72 och P87. Detta ändrar bara kartvisningen på denna enhet, inte dina uppmätta metervärden eller den gemensamma databasen.

Spara kalibreringsfilen på datorn och öppna den sedan på mobilen. Import ersätter bara kartkalibreringen på den enhet du använder, inte fartyg eller pollarmått.

ℹ Kartförklaring
Rödvit ring = vald pollares beräknade kartpunkt. Streckad vit linje kopplar pollaren till fartygets valda referenspunkt. Blå linje = förenklad kajlinje. Fartygens närmaste sida visas cirka 1 meter ut mot vattnet (visuell uppskattning). Spetsig för = vit punkt och FÖR; rak akter = AKTER. Gul markering visar sidan mot kaj. Färgerna visar fartygens läge. Inte godkänd för operativ förtöjning eller lotsbeslut.

Den här prototypen använder exakta längdmått mellan pollarna enligt tabellen. Kajlinjens punkter på flygbilden är däremot manuellt uppskattade och måste kalibreras mot originalritningen innan visuella lägen och kurvpassning kan betraktas som exakta. Avståndskontroll sker längs kajens uppmätta längd, inte utifrån fartygets bredd, svängutrymme, förtöjningsarrangemang eller djupgående.

⚓ Förhandsgranska kajplan

Dra för att flytta, rulla för att zooma eller använd två fingrar på mobilen. Exporten visar valt utsnitt med datum, fartyg och avstånd i kartbilden. Den ändrar inte fartyg eller kartkalibrering. PDF öppnar utskriftsdialogen – välj ”Spara som PDF”.
